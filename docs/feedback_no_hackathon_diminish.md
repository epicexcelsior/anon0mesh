Never say "fine for a hackathon" or frame anything as acceptable-because-hackathon. The app has real deep technology (BLE mesh, Solana, Arcium privacy) and the frontend must match that quality.

**Why:** The user is only handling part of the frontend — the underlying tech is production-grade. Dismissing design quality undermines the entire project and the team's work.

**How to apply:** Always frame design decisions against production-quality standards. The goal is a genuinely excellent app, not a hackathon demo. Treat every screen as if it's shipping to real users.
