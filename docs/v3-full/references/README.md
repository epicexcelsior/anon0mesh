# references/

Drop screenshots, short screen recordings, or image collages from premium apps here as per-screen design references. Agents reference these directly during Phase 2–6 screen rebuilds.

## Folders

- `onboarding/` — welcome / setup / tech drawer / permission priming references
- `home/` — wallet hero, mesh strip, send/receive/history surface references
- `messages/` — conversation list, thread, composer, new-conversation sheet references
- `settings/` — sectioned settings, identity card, network, privacy, export, beacon references
- `send/` — recipient → amount → review → success flow references
- `peers/` — peer sheet, peer detail references
- `haptics/` — short clips demonstrating premium haptic feel (Things 3, Linear, Apple native) for calibration
- `general/` — overall aesthetic / mood references, typography, color palettes

## Naming

Prefix with source app + short description. Examples:
- `home/family-wallet-home-portfolio.png`
- `home/phantom-home-balance-actions.png`
- `send/cash-app-send-confirm-slider.mp4`
- `messages/imessage-thread-haptic.mp4`
- `haptics/linear-button-press.mp4`

## Sources worth mining

- [Mobbin](https://mobbin.com) — curated real-app screens by category
- [Page Flows](https://pageflows.com) — video user flows
- [Screenlane](https://screenlane.com) — free alternative
- Direct: Phantom, Umbra, Backpack, Family (family.co), Cash App, Revolut, Linear, Things 3, Arc Search, Signal, iMessage

## What not to drop here

- Whole app teardown PDFs (too much to scan)
- Designs for unrelated features (chat bots, gaming, etc.)
- Raw Dribbble shots that prioritize visual style over real UX

Lean toward 3–5 high-signal references per screen, not 50.
